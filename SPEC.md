Create a web application for **AGM (Annual General Meeting) management** called "Muktamar". The application should allow users to create and manage AGMs, including scheduling, sending invitations, and tracking attendance.The application should have the following features:  
- User authentication and authorization: Users should be able to create accounts, log in, and manage their AGMs securely.
- AGM creation and management: Users should be able to create new AGMs, set the date and time, and manage the details of the meeting.
- Invitation management: Users should be able to send invitations to attendees via email and track RSVPs.
- Attendance tracking: Users should be able to track attendance during the AGM and generate reports on attendance.
- Notifications: Users should receive notifications for upcoming AGMs and any changes to the meeting details.
- Responsive design: The application should be accessible on both desktop and mobile devices.
- Admin dashboard: An admin dashboard should be available for managing users, AGMs, and overall application settings.
- Data security: Ensure that all user data and AGM information is stored securely and complies with relevant data protection regulations.
- Integration with calendar applications: Allow users to integrate their AGMs with popular calendar applications (e.g., Google Calendar, Outlook) for easy scheduling and reminders.
- Search and filter functionality: Users should be able to search for specific AGMs and filter them based on various criteria (e.g., date, location, attendees).
- Export functionality: Users should be able to export AGM details and attendance reports in various formats (e.g., PDF, Excel).
- User-friendly interface: The application should have an intuitive and user-friendly interface to ensure ease of use for all users, regardless of their technical proficiency.
- Scalability: The application should be designed to handle a large number of users and AGMs without performance issues.
- Support for multiple languages: The application should support multiple languages to cater to a diverse user base.
- API integration: Provide an API for third-party integrations and allow developers to build custom features or connect with other applications.
- Testing and quality assurance: Implement thorough testing to ensure the application is reliable, secure, and free of bugs before deployment.
- Deployment and hosting: Deploy the application on a reliable hosting platform and ensure it is accessible to users globally with minimal downtime.
- Documentation: Provide comprehensive documentation for users and developers, including user guides, API documentation, and troubleshooting resources.

**For MVP (Minimum Viable Product)**, focus on the core features such as user authentication, AGM creation and management, invitation management, and attendance tracking. Additional features can be added in later iterations based on user feedback and demand.
